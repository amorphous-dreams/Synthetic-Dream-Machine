# N8 · The Place That Grows · source and intent boundaries

This contract records a design intention, not a language model runtime.
The operator and current Fire interpret ordinary art direction, then explicitly
author an `IntentContract` and the separately digest-bound `SpatialIntent`.
No art text executes, no source camera changes, and no unaudited geometry
acquires an approved relation.

## Three distinct authorities

- `SpatialGoal` names a falsifiable geometric hypothesis. `connect` has one
  limited native witness in N8-C. `shelter` and `ascend` deliberately return
  `unverified`, never a guessed success. Future implementations must attach
  typed original/native and withheld-counterfactual evidence before admission.
- `PlaceGenome` carries two to sixteen separately inherited `GrowthProgram`
  bodies and bounded named walkways. No scene-wide Boolean union, stable face
  IDs, or mandatory artistic pet-name enters the inheritance.
- `place_affordances.assess_place` reimports independently packaged STEP,
  verifies **both horizontal BRep bearings** and a bounded unoccupied
  eastward axis-aligned agent headroom corridor. This does not measure human
  accessibility, full route planning, engineered load safety or a survey.
  `verify_place_affordances` repeats the native evidence, rejecting changed
  reports rather than trusting visual metadata.

## Design-time consent

The following statements may *only* affect downstream construction after Fire
authors a typed binding. A picture of a bridge does not establish a path.
An imagined refuge does not establish an enclosed court. The operator chooses
which unknowns to retain and whether an unverified goal remains useful as an
artistic study. In particular, reward must not reduce to part count.

## Implementation aftermath

N8-A/B/C implement typed interpretation, multi-body genomes and an actual
two-bearing crossing probe. The initially implemented crossing supports only
an explicitly declared eastward route through one deck. Broader site traversal
and alternative goals remain unimplemented until individually witnessed.
Every N8 claim requires exact-head CI; no new pet-name, canon promotion,
Unreal Editor success, physical certification or implicit PR merge follows.

Experiment anchor: `tests/test_hephaestus_place_affordances.py`.

## N8 · Aftermath II · Source to generation without a shadow controller

The current campaign runner calls the existing `OODAHAJournal`; it does not
install a model interpreter, new five-phase authority, or one-run camera score.
An `IntentContract` authorizes the run identity, a separately authored spatial
binding constrains construction, and each accepted `PlaceGenome` regrows from
its own immutable program into a source/causal/native `location_workspace`.
The inherited place contains independent solids, not one bogus global union.

`spatial_niches` and individually attributed candidate receipts preserve
several geometrically distinct interpretations. Morphology does not grant
truth: every descendant independently undergoes exact STEP bearings and
bounded corridor headroom. A candidate that lacks a complete spatial witness
keeps `spatial-unverified` status instead of receiving a visual-loss penalty
or claiming native failure. An unattempted proposal remains deferred under
finite budget rather than falsely rejected. The operator chooses what to
retain; a niche does not select an artistic winner.

Known limits: native route witness currently implements one eastward walkway
and an axis-aligned agent envelope. The inherited construction grammar still
uses `foundation/spawn/split/bridge/carve` within each body. The study does
not infer unobserved real-world scale, certified accessibility, load,
human experience, or survey truth. A review or export cannot promote canon.

## N8 · Intent aftermath IV · A relation makes a change, not a label

The new `propose_from_spatial_intent` creates a bounded additional
construction body ONLY when the operator/Fire explicitly author a `connect`
goal between two known, simple rooted support sites. Their authored dimensions
and placements determine the deck's constructive program, not image pixels,
language tokens, or arbitrary OpenCascade face identifiers. Existing declared
walkways remain untouched. The original genome and the constructed genome
each keep full separate content digests in the preregistration.

North/south and either horizontal direction use the same native bearing test;
diagonal and different-level supports still refuse. `shelter` and `ascend`
continue as explicit unimplemented architectural hypotheses. This limited
contrast establishes genuine intent sensitivity for a finite case, not
generalized text-to-architecture or human interpretation of a sanctuary.
Operator and Fire attribution describes the authored record; it does not
cryptographically authenticate its human author.

The native corridor uses a bounded axis-aligned agent envelope; no formula
silently turns that witness into building-code accessibility or physical
load-bearing certification. Equal camera/source testimonies survive unchanged.

## N8 · Aftermath V · Operator acceptance changes subsequent ancestry

The new `place-continue` CLI only accepts an immutable, attributable
`location_review` with decision `accept`, tied to exactly one admitted
prior candidate. An `abstain`, `dissent`, missing candidate, tampered
source, or stale review refuses before new generation. The new study copies
its previously audited native parent and review as independently rehydratable
evidence, then inherits its original construction genome and runs it through
the SAME OODA-HA journal class as any other place campaign. The original
generation and review remain unchanged. The lineage type explicitly states
`attributed-study-lineage`, not an editor causal reparent, engineering
load review, artistic winner, or mythic pet-name decision.

A source inventory may still require access to the original source files
when continuing a lineage: absent bytes cause a refusal, never an
unacknowledged upgrade in source authority. The copied parent workspace
preserves the earlier source archive and verifies its own claims; it does
not magically authenticate the source creator or repair missing sensors.

## N8 · Aftermath VII · Evidence authority across source and native archives

Source-poor and original-file-backed campaigns receive different scope labels
inside the immutable pre-registration. An image-free synthetic geometry input
does not acquire `image-IoU`, calibrated world scale, or external survey
authority simply because its STEP bodies pass. A source file backed by exact
matched original bytes grants **byte testimony**, not its author's credibility,
physical measurement authority, or a registered camera.

The source-continuity adversarial test changes the external source file AFTER
the first candidate workspace freezes its content-addressed archive. Reopening
that candidate still verifies the preserved original testimony. Beginning
another campaign with the stale original inventory refuses BEFORE new output
publication. No silent re-hashing or auto-upgrading the changed evidence.

N8 remains an early-alpha bounded generative place study, not a general
topological theorem or an artistic judge. Each new relation needs its own
constructive and counterfactual native witnesses. Converging the existing
generalized campaign and the place campaign's phase orchestration without
installing a second helm remains an explicit future refactor priority.

## N8 · Aftermath VIII · Fire is an interpreter, not an executable free-text engine

`fire_spatial.bind_fire_spatial` consumes the existing **verified typed Fire
plan** through an explicit alternative ID, matching a source witness and a
known intent/location. Both material endpoints must already resolve to
different real location-body handles. Only `bridges/bridge-between` maps to
the presently witnessed `SpatialGoal(connect)`. A poetically compelling
`encircles` or other artistic relation does not gain a fake passage by
being proximate to a constructed form; it remains in its own study context
until a trustworthy native method exists.

This code does not parse art prose, generate language, issue identity
claims, certify survey sources, or choose among Fire alternatives.
The binding contains the original Fire plan digest, selected proposal ID,
source-witness handle, typed interpretation identity and a no-promotion
claim. An independent verifier reconstructs those fields from the same
witnesses before any native construction is proposed.

The operator may continue to speak Art Sigils at the existing expressive
level; the compiler only receives bounded, source-bound proposals.

## N8 · Aftermath X · A place can require several separately evidenced bridges

A `connect` goal now admits an explicitly authored **unique directed
walkway chain** through up to eight separately named native deck segments.
Each step independently reimports actual STEP solids, verifies both real
planar bearing contacts, the authored step-height bound, and an empty bounded
agent corridor; full lineage preserves each segment's own independent
hash. Competing reachable chains produce a typed refusal rather than an
undisclosed automatic route choice. Disconnected locations stay free to
contain independent native solids.

Only axis-aligned horizontal bridges receive this witness. An existing
multi-hop relation takes precedence over adding a new direct bridge: the
operator's already authored route cannot be silently rewritten. Crossings
may pass through several named places; that still does not establish
wheelchair accessibility, true human circulation over slopes, engineered
stability, environmental safety or a visually compelling interpretation.
The creative intent must remain separate from these finite mechanical tests.

## N8 · Aftermath XII · Language, verified program, and approved choice

`fire-place-bind` now exposes the already-existing typed `fire_spatial`
adapter through the main CLI. It consumes an exact Fire-bound plan,
unmodified original-source witness identity, an operator-specified
alternative ID, the immutable explicit `IntentContract`, and a
source-independent `PlaceGenome` with real endpoint handles. The CLI
writes an immutable result that can provide the `spatial` input to
`place-run`; the companion `fire-place-verify` reconstructs every field
against the unchanged original plan and intent. Tampered witness IDs or
missing alternative aliases refuse before any artifact publishes.

The native construction layer still knows no natural-language Art Sigil
parser, no model daemon, and no art-directed automatic winner. A Fire
`bridges` relation produces a bounded crossing proposal ONLY after
the operator explicitly selects and binds that proposal. `shelter`,
`ascend`, `ring-around`, and other interpretive relations do not
silently become a generative bridge implementation.

This improves the handoff from creative intention to CAD program without
surrendering independent construction truth, source authority, review or
causal ancestry to the author's metaphors. Existing `place-review` for
Fire's read-only carved-native passage studies remains untouched:
new operator review uses `place-candidate-review`.
