# A wide epoch holds bounded inner loops

`WideEpoch` admits candidates through explicit modes and stages:

1. **Propose** via seeded Sobol, local parameter mutation or declared topology
   switch parameters. These generate finite genomes, not validated geometry.
2. **Preview** only prioritizes the exact-audit budget. A deferred candidate
   does not acquire an invalid or failed-CAD label.
3. **Audit** requires valid parent contacts, a single per-body Boolean material
   union, and all authored void connections. This exact gate never delegates to
   a proxy image or sampled surface.
4. **Compare** only when every declared objective returns a finite measurement.
   A metric unavailable from source evidence must be omitted from the **entire
   experiment contract**, not treated as a candidate-specific zero.
5. **Archive** one elite per observed relational phenotype; retain the source
   evidence state (`synthetic`, `provisional`, `verified`) and soft pet-name loss
   separately from measured loss. Resumable checkpoints record a source digest,
   construction-code digest, proposal roster, seed, budgets and every result.

`run_ooda_ha_epochs` governs the active CLI and re-enters the selected *genome*.
The lower-level `run_project_epochs` test helper also offers deterministic
reentry. Every next model regrows from the builder and the same fixed scoring
reference. No loop promotes a
self-generated mask into a new external measurement. The CLI includes
`wide-epoch`, `inspect-dem` and `register-control`.

## Forbidden shortcuts

- An approximate preview cannot admit a CAD model.
- An evaluator exception cannot be attributed to an invalid construction.
- A provisional camera never becomes verified by achieving a low image loss.
- A model's novelty never relaxes its material/void validity.
- A shared dataset cannot be silently altered across resumed epochs.
- Missing sources cannot become a zero loss.
- An old archive's parameter count or camera index never enters active tests.

## Remaining frontiers

Active implementation does not perform general likelihood estimation, automatic
multi-photo SfM, implicit geometry reconstruction, texture inversion, learning
new grammar macros, or active next-best-view suggestions. These require
separately validated backends and research trials.

The active `wide-epoch` CLI now uses [guarded nested OODA-HA](../ooda-ha-procedural.md) with human review boundaries.
