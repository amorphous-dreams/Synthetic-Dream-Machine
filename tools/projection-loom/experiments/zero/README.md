# Experiment Zero · seven seed combinations

This directory supplies exactly three independent example inputs:
`inputs/image_group/manifest.json` (original Necrospire artwork and L8 alpha
as two channels of one source), `inputs/brutalist_grammar/grammar.json`
(authored constructive rules), and `inputs/ziggurat_proxy/proxy.json`
(authored geometric hypothesis).

Each works alone, in three pairings, and combined. The generic engine under
`projection_loom/` never imports this directory. Each cohort runs through
the **existing** OODAHAJournal, not a second controller. Native exact audits,
reproducible structural genomes, seed-frozen synthetic orthographic views,
original-source native-resolution finalist scores and failure receipts are
stored under one run identity. Image-free cohorts cannot receive invented IoU.

Run from tools/projection-loom:
```bash
python -m projection_loom.generalized_campaign \
  --inputs experiments/zero/inputs \
  --out out/generalized-experiment-zero \
  --epochs 3 --offspring 4 --exact-budget 4 --finalists 2
```
The original artwork's pose remains **provisional**, not a metric camera or
survey. A second unrelated image is independent testimony, not a channel;
additional camera registration needs independent anchors. An operator must
inspect candidates before any pet-name or canon promotion.
