## Executable operating boundary

From `tools/projection-loom`, the main entry point is `python -m projection_loom`; inspect `python -m projection_loom --help` for live commands and arguments. Architectural and source-integrity checks live in `scripts/check_architecture.py`. Invoke the tests through `python -m pytest -q tests` in an environment with the package and its native CAD dependencies installed. Existing CLI, tests and actual receipts outrank old narrative examples.

The single `projection_loom.fractal_ooda_ha` control helm owns generational work. Capabilities, galleries, native STEP, OpenUSD and Blender are subordinate witnesses/adapters; there is no second mutable evolutionary controller. A source-refused construction must not be labeled a native rejection or granted a fabricated STEP receipt.
