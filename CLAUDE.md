## Claude Adapter Surface

- Keep this file thin.
- Add only Claude-specific customizations here.
- The seed seats by reference (lar:///ha.ka.ba/lares/docs/pono/seed-seat): `.claude/noosphere-boot` links to the boot seed, since an import loads a file by its name and a `.mem` loads nothing. Explore and Plan skip CLAUDE.md, so `.claude/agents/{Explore,Plan}.md` carry the seed as a projection the root build writes. `lares repo tend` keeps the checkout's seat and `lares home tend` the operator's own rule, which `.claude/settings.json` excludes inside the clone; `tools/repo-tunnel-witness.sh` reads the checkout.
- `LAR_ROOT` names the ONE house root, and every house-state resolver requires it: unset or blank refuses (`HouseRootUnnamed`), with no XDG or home-directory fallback. Beneath it: `hearth/` (vessel, identity, nexus, checkpoints, staging; a re-founding clears it alone), `sensoriums/` (captured conversation memory, never projected, outside every re-found), `library/`, `projections/` (the authored memory stage and every other plaintext render), `config/`, `cache/`, `run/`. The container sets `/lar`; the host shim binds `$LARES_HOUSE/{hearth,sensoriums,projections,library,config}` there.
- Projection follows placement: a record reaches plaintext only through a resting layer with a mirror, and INGEST accepts a wave only when the vessel grants that source root to the selected bag. Titles and `bag` fields do not choose residency. `$:/config/lares/ProjectionFilter` carries the temp/state preferences; the temp class may withhold house config. Control and secret homes carry no mirror.
- So the tracked tree takes writes in one case: a boot whose canon source resolves to the checkout's `bags/` (`LAR_BAGS=<checkout>/bags`, or a config naming it), where live edits to every canon-sourced bag (lares, lararium, crossroads, any dir standing there) land in the tracked `bags/` and `wikis/` by design, as source-control write-back, even under a scratch `LAR_ROOT`. A scratch `LAR_ROOT` with no `LAR_BAGS` and no config naming the checkout stays isolated: store, canon source and every mirror move under it (genesis too; `LAR_GENESIS` overrides). Isolate every dev/smoke boot that way. Suites name a scratch `LAR_ROOT` per worker (`tools/vitest-scratch-house.mjs`, the pytest conftest); e2e: a scratch `LAR_ROOT` per vessel, no global `LAR_BAGS`. `tools/tree-clean-witness.sh` reads any write into the tracked tree as red.
